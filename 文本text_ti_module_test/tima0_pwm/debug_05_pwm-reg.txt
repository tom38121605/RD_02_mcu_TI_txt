

0. 问： PINCM[31] =  6<<0 表示什么意思

答   在 MSPM0G3507 数据手册， p12页的“表 6-1. 引脚属性”，
       每一行是一个引脚，其中 DIGITAL [PIN FUNCTION] 这一列，会列出该引脚所有可选的数字外设功能，方括号里的数字就是 PF 的值。
       PA31对应的是： UART0_RX [2] / I2C0_SCL [3] / TIMA0_C3N [4] /TIMG12_C1 [5] / CLK_OUT [6]/ TIMG7_C1 [7] / TIMA1_C1[8]
       6  --  对应  CLK_OUT [6]    //定时器通过引脚输出



1. pwm和timer分频计算时钟频率：

    分频后的时钟频率  ftime=  主频 80M / (div +1)  / (pscal +1)   = 80/ 2 / 4 = 10M

    .clockSel = DL_TIMER_CLOCK_BUSCLK,         //1<<3          //80MHz
    .divideRatio = DL_TIMER_CLOCK_DIVIDE_2,    //001<<0
    .prescale = 3U                             //3



2. PWM频率计数：
   fpwm = ftime / period count /2  =   10M / 1000 /2  =  50Khz

   .period count  = 1000
